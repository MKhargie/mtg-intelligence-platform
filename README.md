# MTG Intelligence Platform



## Overview



MTG Intelligence Platform is an early-stage project exploring tools that help Magic: The Gathering players understand and improve their decks. The project will focus on turning deck information into clear, actionable feedback.



## Project Status



The project is currently in product discovery and repository setup. Its first user workflow and feature scope have not yet been finalized.



## Current Direction



The initial direction is a deck theory-crafting assistant that helps players evaluate a deck, understand potential weaknesses, and identify possible improvements. Product discovery will determine the first narrow problem the application should solve.



## Repository Structure

- `project/` - Contains the product vision, backlog, feature briefs, engineering tickets, and project decisions.

## Development Workflow



Changes are developed on focused branches and integrated through reviewable pull requests. Commits should be small and clearly described, with tests and validation appropriate to the risk of each change.

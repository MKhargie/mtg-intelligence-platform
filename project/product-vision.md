# Product Vision

## Working product

MTG Intelligence Platform

## Current hypothesis

Build a useful application that helps Magic: The Gathering players turn card, deck, metagame, or collection data into decisions. The exact first user and problem remain to be chosen through product discovery.

## Product principles

- Solve a recognizable player problem.
- Prefer a narrow end-to-end workflow over a broad collection of disconnected tools.
- Let user value drive technical complexity.
- Treat uncertain product claims as hypotheses to validate.

## Open decisions

- Primary user segment
- First high-value problem
- Initial data sources and their constraints
- Definition of a useful first release
